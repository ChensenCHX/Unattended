# FacilityEther

## Basic Info

| Property | Value |
|----------|-------|
| Resource | Ether |
| Build Cost | Mana |
| Degenerates To | Mana |
| Build Prerequisite | Plot based on Mana |

## Core Rule

Ether's **growth duration** and **harvest yield** are both affected by the number of adjacent same-type facilities. More adjacent Ether facilities cause exponential growth-time increase and yield reduction. Dense Ether clusters are inefficient per-facility; players must balance density against output.

## Strategy Tips

- Avoid clustering Ether in one area; spread them apart
- Interleave lower-tier facilities to dilute the density penalty
- If density is too high, build a lower-tier facility on top of Ether to remove the penalty
