# FacilityEther

## 基本信息

| 项目 | 说明 |
|------|------|
| 产出资源 | Ether |
| 建造消耗 | Mana |
| 收获后退化 | Mana |
| 建造前置 | 基于 Mana 的地块 |

## 核心规则

Ether 的**生长时长**和**收获产量**均受周围相同设施数量的影响。周围 Ether 越多，生长所需时间指数增长，产量相应下降。这意味着密集建造 Ether 不利于单设施的效率，玩家需要在密度与产量之间权衡。

## 策略提示

- 避免将所有 Ether 集中建造在同一区域，应尽量分散布局
- 可以配合低级设施穿插建造，稀释相邻 Ether 的密度惩罚
- 如果某区域密度过高导致生长过慢，可以在 Ether 上回退建造低级设施以解除惩罚
