# FacilityIter

## 基本情報

| 項目 | 値 |
|------|-----|
| 資源 | Iter |
| 建設コスト | Ether + Signum |
| 退化先 | Ether |
| 建設前提 | Signum ベースの区画 |

## コアルール

FacilityIter は**グラフ接続性の最適化**を中心に設計されています。建設時、他 Iter 施設との間にランダムな重み付き辺が生成され、無向グラフを形成します。収量 = 基本収量 × 連鎖収穫数³ / 全アクティブ辺の重み合計。

プレイヤーは以下でグラフを調整できます：
- `connect(x, y)`：座標 (x, y) の Iter へ接続
- `disconnect(x, y)`：座標 (x, y) の Iter との接続を解除

収穫時、直接的または間接的に接続された全 Iter が連鎖収穫されます。

## 戦略のヒント

- 辺の重みが収量に直接影響します。高重み辺は全体の出力を下げる
- アクティブ辺数（連鎖数増加）と重み合計（分母減少）のバランスが重要
- 高重み辺を切断し、より最適な位置に再接続する
- グラフ理論（接続性、辺重み最適化、スパニングツリー）の理解が試される

## インタラクションメソッド

| メソッド | シグネチャ | 説明 |
|----------|-----------|------|
| `get_edges` | `get_edges() → table` | `{x=[...], y=[...], weight=[...], state=[...]}` の 4 並列配列を返す |
| `connect` | `connect(int x, int y) → bool` | 指定座標の Iter への接続を試行、成功時 true |
| `disconnect` | `disconnect(int x, int y) → bool` | 指定座標の Iter との切断を試行、成功時 true |
