# FacilityMana

## Basic Info

| Property | Value |
|----------|-------|
| Resource | Mana |
| Build Cost | None |
| Degenerates To | Empty |
| Build Prerequisite | Any plot (including Empty) |

## Core Rule

Mana is the most basic facility with no special rules. It grows over time after being built, and can be harvested once growth completes. After harvesting, it degenerates to an Empty plot. Players must rebuild to continue production.

## Strategy Tips

- This is your first facility; practice the basic "build–wait–harvest" loop
- Start with a single Mana automation, then expand to parallel management of multiple plots
- Mana is the foundation for all higher-tier facilities; ensure stable output
