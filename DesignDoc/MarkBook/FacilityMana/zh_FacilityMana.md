# FacilityMana

## 基本信息

| 项目 | 说明 |
|------|------|
| 产出资源 | Mana |
| 建造消耗 | 无 |
| 收获后退化 | Empty |
| 建造前置 | 任意地块（包括 Empty） |

## 核心规则

Mana 是最基础的设施类型，不具备特殊规则。设施建造后随时间自动生长，生长完成后即可收获。收获后设施退化为 Empty 地块，玩家需要重新建造以持续生产。

## 策略提示

- 这是你接触的第一个设施，适合练习基本的"建造—等待—收获"循环脚本
- 建议先实现单个 Mana 的自动收获，再扩展到多个地块的并行管理
- Mana 是所有高级设施的建造基础，需要保证稳定的产出

## 交互接口

可通过 `interact_with(name, ...)` 调用的方法：

| 方法 | 签名 | 说明 |
|------|------|------|
| 无 | — | Mana 不提供自定义交互方法 |
