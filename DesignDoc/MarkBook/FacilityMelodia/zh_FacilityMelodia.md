# FacilityMelodia

## 基本信息

| 项目 | 说明 |
|------|------|
| 产出资源 | Melodia |
| 建造消耗 | Ether |
| 收获后退化 | Mana |
| 建造前置 | 基于 Mana 的地块 |

## 核心规则

每个 Melodia 设施持有一个 **音调值（Tone）**，取值范围 0~31。收获 Melodia 时，如果当前收获的音调值与上一次收获的不同，可获得递增的额外产出倍率；如果与之前的音调值重复，倍率将重置。倍率上限为 16×。

## 策略提示

- 需要记录历史收获的音调序列，避免重复导致加成重置
- 音调值通过 ` + "interact_with(\get_tone\)" + @" 查询，可以提前规划收获顺序
- 当队列积累到 32 种或出现重复时，队列自动清空
- 考察玩家对数据结构和排序算法的理解

## 交互接口

| 方法 | 签名 | 说明 |
|------|------|------|
| ` + "get_tone" + @" | ` + "get_tone() → int" + @" | 返回设施的当前音调值（0~31） |

> 全局音调队列在收获时自动维护：连续不同音调累积加成，重复则自动清零。无需手动 reset。
