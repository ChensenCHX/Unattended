# 物品效果说明

游戏中包含七种物品类型，与设施类型一一对应。物品除作为科技树解锁的消耗品外，还具有各自的持有被动效果和主动使用效果。

## 物品效果一览

| 物品 | 持有时的被动效果 | 主动使用（`use_item`）效果 |
|------|-----------------|--------------------------|
| **Mana** | 无 | — |
| **Ether** | 无 | — |
| **Melodia** | 持有后自动消耗，提高可操作单位的每帧指令执行量 | — |
| **Chronos** | 无 | 对设施使用后使设施生长加速 |
| **Signum** | 持有后自动消耗，提高可操作单位的每帧指令执行上限 | — |
| **Iter** | 持有后自动消耗，缩短可操作单位的移动时间 | — |
| **Opus** | 无 | 对设施使用后使设施直接生长完成 |

## 注意事项

- 被动效果在持有对应资源时自动生效，消耗量取决于解锁的科技级别
- 使用 `use_item(type)` 前请确认可操作单位当前所在坐标的目标设施
- 物品使用失败（设施不接受此物品或物品数量不足）时不会扣除物品
