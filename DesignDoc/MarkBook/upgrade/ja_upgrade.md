# テクノロジーツリー

テクノロジーツリーでは、蓄積した資源を消費して永続的な能力向上を得られます。技術ノード間には段階的な依存関係があります。

## 技術次元

| 次元 | レベル範囲 | コア効果 |
|------|-----------|---------|
| 言語機能 | 1～8 | Lua 言語機能を段階的に解放：テーブル、クロージャ、無名関数、コルーチン、メタテーブル |
| 移動速度 | 1～5 | グリッド間のユニット移動時間を短縮 |
| ワークスペース | 1～5 | グリッドマップの辺長を拡大、建設可能エリアを増加 |
| スレッド数 | 1～5 | 同時実行可能な並列スレッドの上限を増加 |
| 命令実行 | 1～5 | スレッド毎フレームの最大命令数を増加 |
| マルチスレッド | 単独 | 複数スレッドの同時作成を可能化 |

## アンロック条件

各技術ノードには以下が必要です：
1. 全ての前提依存ノードがアンロック済み
2. 必要な資源コストの支払い

上位ノードは複数種の資源を要求する場合があります。保留中ノードをクリックすると資源が即時消費され、効果が適用されます。
